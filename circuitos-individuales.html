Circuito 01 — Temperatura y humedad

Sensor DHT22 con módulo relevador

Mide la temperatura y humedad del aire y activa un relevador (que a su vez controla el ventilador) cuando la temperatura supera el umbral programado.

Arduino UNO + DHT22 + Relé 1 canal Prueba individual · Control por temperatura
  • Pin 7 Señal de datos del sensor DHT22.
  • Pin 8 Entrada IN del módulo relé.
  • 5V / GND Alimentación compartida del DHT22 y del relé.
circuito_1_dht22_rele.inoArduino UNO
// Circuito 1: Sensor DHT22 + Módulo relé // Enciende el relé (ventilador) cuando la temperatura supera el umbral #include <DHT.h> #define DHTPIN 7 // Pin de datos del DHT22 #define DHTTYPE DHT22 // Tipo de sensor #define RELAY_PIN 8 // Pin conectado a IN del relé const float TEMP_MAXIMA = 28.0; // °C — umbral para encender el ventilador DHT dht(DHTPIN, DHTTYPE); void setup() { Serial.begin(9600); pinMode(RELAY_PIN, OUTPUT); digitalWrite(RELAY_PIN, LOW); // Relé apagado al iniciar dht.begin(); } void loop() { float temperatura = dht.readTemperature(); float humedad = dht.readHumidity(); if (isnan(temperatura) || isnan(humedad)) { Serial.println("Error al leer el sensor DHT22"); return; } Serial.print("Temp: "); Serial.print(temperatura); Serial.print(" C Humedad: "); Serial.print(humedad); Serial.println(" %"); if (temperatura > TEMP_MAXIMA) { digitalWrite(RELAY_PIN, HIGH); // Enciende el ventilador } else { digitalWrite(RELAY_PIN, LOW); // Apaga el ventilador } delay(2000); // El DHT22 necesita ~2s entre lecturas }

Requiere la librería DHT sensor library (Adafruit) desde el Gestor de Librerías del IDE de Arduino.

Circuito 02 — Riego

Sensor de humedad del suelo con pantalla LCD y bomba

Lee la humedad del sustrato, muestra el valor en una pantalla LCD I2C y activa la bomba de agua cuando la tierra está seca.

Arduino UNO + sensor de suelo + LCD I2C + bomba Prueba individual · Riego automático
  • A0 Salida analógica del sensor de humedad del suelo.
  • SDA / SCL Pantalla LCD 16×2 con módulo I2C.
  • Pin 8 Control de la bomba de agua (a través de un relé o transistor).
circuito_2_suelo_lcd_bomba.inoArduino UNO
// Circuito 2: Sensor de humedad del suelo + LCD I2C + Bomba de agua // Muestra el porcentaje de humedad y riega automáticamente si la tierra está seca #include <Wire.h> #include <LiquidCrystal_I2C.h> #define SOIL_PIN A0 // Salida analógica del sensor de suelo #define PUMP_PIN 8 // Pin de control de la bomba (vía relé/transistor) const int SUELO_SECO = 600; // Lectura analógica con tierra seca (ajustar con pruebas) const int SUELO_MOJADO = 280; // Lectura analógica con tierra húmeda (ajustar con pruebas) LiquidCrystal_I2C lcd(0x27, 16, 2); // Dirección I2C típica 0x27 void setup() { Serial.begin(9600); pinMode(PUMP_PIN, OUTPUT); digitalWrite(PUMP_PIN, LOW); lcd.init(); lcd.backlight(); } void loop() { int lectura = analogRead(SOIL_PIN); int porcentaje = map(lectura, SUELO_SECO, SUELO_MOJADO, 0, 100); porcentaje = constrain(porcentaje, 0, 100); lcd.clear(); lcd.setCursor(0, 0); lcd.print("H.Suelo: "); lcd.print(porcentaje); lcd.print("%"); lcd.setCursor(0, 1); if (porcentaje < 30) { digitalWrite(PUMP_PIN, HIGH); // Tierra seca: enciende la bomba lcd.print("Regando..."); } else { digitalWrite(PUMP_PIN, LOW); // Humedad suficiente: apaga la bomba lcd.print("Suelo OK"); } delay(1000); }

Requiere las librerías Wire (incluida en el IDE) y LiquidCrystal I2C. La bomba nunca debe alimentarse directamente desde un pin del Arduino: siempre a través de un relé o transistor con fuente externa.

Circuito 03 — Iluminación

Fotorresistencia (LDR) con barra de LEDs

Mide la cantidad de luz ambiental y enciende los LEDs de forma proporcional a la oscuridad, simulando el encendido de una luz de apoyo cuando falta sol.

Arduino UNO + LDR + 5 LEDs Prueba individual · Iluminación por luz ambiental
  • A1 Divisor de voltaje con la fotorresistencia (LDR).
  • Pin 9 (PWM) Barra de 5 LEDs con resistencia limitadora.
circuito_3_ldr_leds.inoArduino UNO
// Circuito 3: Fotorresistencia (LDR) + barra de LEDs // A menor luz ambiental, mayor brillo de los LEDs (luz de apoyo automática) #define LDR_PIN A1 // Divisor de voltaje con el LDR #define LED_PIN 9 // Pin PWM de la barra de LEDs const int LUZ_MINIMA = 200; // Lectura con buena luz ambiental (ajustar con pruebas) const int LUZ_MAXIMA = 800; // Lectura en oscuridad (ajustar con pruebas) void setup() { Serial.begin(9600); pinMode(LED_PIN, OUTPUT); } void loop() { int luz = analogRead(LDR_PIN); // A mayor lectura (más oscuro), mayor brillo de los LEDs int brillo = map(luz, LUZ_MINIMA, LUZ_MAXIMA, 0, 255); brillo = constrain(brillo, 0, 255); analogWrite(LED_PIN, brillo); Serial.print("Luz: "); Serial.print(luz); Serial.print(" Brillo LEDs: "); Serial.println(brillo); delay(300); }

El pin 9 admite PWM, por lo que analogWrite controla el brillo de forma gradual en lugar de solo encender o apagar los LEDs.
